# End-to-end user journeys

Run against the real built Studio and implemented Phase-1 service with deterministic
ports unless native permission is separately recorded. Each journey needs an exact
build/source/registry/API lock, role, fixture, effect counters and sanitized evidence.

## J01 — Connect and inspect without operating
Pair as a viewer; load compatibility and a published workflow; inspect a live run,
node invocation and approved artifact. Attempt an unauthorized control directly.
Expect useful read views, exact source/digest binding and server-side denial of
write. Refresh/deep-link successfully. No provider/game call is caused by reads.

## J02 — Build a strict workflow without dragging
As author, clone an admitted template. Use palette/button/list commands to add,
connect and configure nodes; set a true/false/unknown guard; inspect a protected
action composite; validate. Repeat the essential edits keyboard-only. Both routes
produce the same admitted semantic candidate and no unlocked internal steps.

## J03 — Canonical round-trip and layout isolation
Import a full supported definition; compile it; move, align, collapse and auto-layout
nodes; export and compile again. Digests/semantics follow owner equivalence. Then
change one guard/branch ordering, inspect semantic diff, undo and restore the
original. Raw-byte formatting differences are not confused with semantic identity.

## J04 — Nested subworkflow and clipboard
Open nested graph breadcrumbs, inspect pinned library reference, copy a subgraph
with data bindings, paste twice, validate new local IDs and stable external refs.
Delete a referenced node and review impact. Undo all compound operations without
leaving dangling edges, bindings or history corruption.

## J05 — Incomplete raw text and durable draft
Enter malformed raw JSON and preserve it as a bounded non-runnable draft if the
admitted authoring contract supports raw state. Repair and apply atomically.
Save, close browser, restart owner store/service in the test environment, reconnect
and recover the draft/layout. No false valid/published state during malformed input.

## J06 — Concurrent authoring conflict
Two tabs open the same revision; one changes layout and guard order, the other
changes a referenced node. Save both. Review base/local/remote, resolve a semantic
conflict or keep local as new. All local edits remain until acknowledged resolution;
authoritative validation reruns. No last-write-wins overwrite.

## J07 — Publish separately from run
Validate a precise candidate; publish and prove zero provider/game effects. Start
only that immutable digest with a permitted profile after explicit admission.
Drop response after acceptance, reattach and resolve the original run identity.
No duplicate run and no implicit launch from publish.

## J08 — Pause, step, cancel and uncertainty
Observe a running fixture, pause through its admitted command, show Pausing until
settled. Step one supported semantic unit, then cancel future work. Inject unknown
action outcome and confirm the UI cannot force complete/retry or step another
mutation. Workflow cancellation and game outcome are independent fields.

## J09 — Disconnect and stream repair
Attach at snapshot/cursor; deliver duplicate/split frames; disconnect and reconnect.
Inject retention gap and slow-client overflow. Expect stale/resync and authoritative
snapshot recovery, no fabricated node completion. Close tab while accepted run
continues; reconnect to the same run, not a replacement.

## J10 — Dynamic authoring and live plan history
Author a bounded region under actual registry policy. With two controlled Phase-1
inputs, show two accepted plan topologies and their revision diff. Observe a rejected
or superseded plan as read-only evidence. Edit a future draft budget; verify the
active run remains pinned. No graph generation timer or live-plan patch API.

## J11 — Historical replay and comparison
Switch an active run to historical cursor mode. Step recorded events, inspect
a gap/redacted artifact and invoke actual offline replay. Prove zero provider/game
mutations. Compare two definitions and runs without confusing layout changes,
seed/provider differences, or unmatched invocations with causal effectiveness.

## J12 — Permissions, accessibility and handoff
Revoke session while on a sensitive view, change role/server, test malicious import,
then reauthorize and inspect required core screens at desktop/narrow/zoomed/reduced-
motion settings. Export a sanitized support packet. Confirm no token/private data
in browser storage, logs or screenshots. Execute the documented bundle acceptance/
rollback dry run without deploying, installing or restarting a real host.
