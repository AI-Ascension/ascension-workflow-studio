Resolve exact `AI-Ascension/ascension-workflow-studio` with the current connector/
Git environment. Inspect existing work and policies. A permission failure is not
absence. If absent and creation is authorized, create exactly that repository,
private unless the operator explicitly authorizes another visibility. No sibling
renames or near-name fallback. Check current naming/standards policy and record
any approved new frontend profile.

Initialize useful product source, contracts acceptance, tests and docs in a feature
branch. An empty-repository bootstrap commit may establish a PR base, but must
not masquerade as the implementation. Import this package with its source manifest
and mark it as planning input. Respect source licenses/provenance. Generate no
credentials and commit no private artifacts.

Use current available GitHub/repository tools for creation and writes. If the
capability is missing or denied, preserve the local implementation/patch and
record a blocked create/push gate instead of bypassing authorization. Assignment
uses the authenticated operator; draft PR delivery does not authorize merging.
